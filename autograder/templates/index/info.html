2025–2026 TJCT Grader Guide

Verdicts

  • Accepted (AC) — Your submission passed all our tests.
  • Wrong Answer (WA) — Failed a test. You will not be able to see what the input you failed on was unless it was the first one. Try creating and debugging on edge cases to catch the error.
  • Compilation/Runtime Error — Your code encountered an error. Check the feedback for more detailed comments.
  • Time Limit Exceeded (TLE) — Your code was too slow. Reduce time complexity. Our servers run around 109 operations a second. Default time limits: 1s C++, 2s Java, 3s Python.
  • Memory Limit Exceeded (MLE) — Too much memory used. Default memory limit is 256 MB.
  • Running (RN) — Code is running. Reload the page to check. If it hasn't finished for a couple minutes, resubmit; if that fails, let us know.

Feedback

By clicking on the ID of the submission, you can view additional feedback. Feedback is available for the first test.

Submissions

Your code should take input from standard in and output to standard out. Use cin/cout (C++), input() (Python), or Scanner (Java). We recommend using https://ide.usaco.guide/.

Java users, make sure your class is named usercode. We encourage Python or C++.

Example code to sum the array (see usaco.guide/general/input-output):

Java

package subcode;
import java.util.*;
import java.io.*;
public class test {
    public static void main (String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextInt();
        }
        long sum = 0;
        for (int i = 0; i < n; i++) {
            sum += a[i];
        }
        System.out.println(sum);
    }
}

C++

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n; cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    long long ans = 0;
    for (int i = 0; i < n; i++) {
        ans += a[i];
    }
    cout << ans << "\n";
}

Python

n = int(input())
a = list(map(int, input().split()))
print(sum(a))

Standings

Standings are determined by total points, where each problem solved rewards a set amount of points; ties broken by penalty. Penalty for each problem = minutes to solve + 10 minutes per wrong submission. Overall penalty is the sum across solved problems. Numbers in problem columns denote the number of submissions taken to solve, negative if unsolved.

2025–2026 TJCT Grader Guide
Verdicts

Accepted (AC) — Congratulations! Your submission passed all our tests.

Wrong Answer (WA) — Try again! Your submission failed a test and thus didn’t solve the problem correctly. You will not be able to see what the input you failed on was unless it was the first one. Try creating and debugging on edge cases to catch the error!

Compilation/Runtime Error — Your code encountered an error. Check the feedback which might provide more detailed comments. This means your code does not follow the rules of the programming language and did something illegal.

Time Limit Exceeded (TLE) — Your code was too slow. Try reducing time complexity or optimizing your code. Note that our servers can only run around 109 operations a second. The default time limits for problems are 1 second for C++, 2 seconds for Java, and 3 seconds for Python.

Memory Limit Exceeded (MLE) — Your code used too much memory. Store less information. The default memory limit is 256 megabytes.

Running (RN) — Your code is currently running. Reload the page to check if your code has finished running. If it hasn’t finished for a couple minutes, our servers probably encountered an error. Try resubmitting. If that doesn’t work, please let us know.
